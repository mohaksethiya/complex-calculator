# Python Calculator

A Python-based calculator that evaluates mathematical expressions while following standard operator precedence and parentheses.

## Features

- Evaluates mathematical expressions.
- Follows standard operator precedence (BODMAS).
- Supports parentheses for controlling the order of operations.
- Uses a custom expression parser to process calculations.

## Usage

1. Clone or download this repository.
2. Run the calculator using Python.
3. Enter a mathematically valid expression.
4. View the calculated result.

### Important

**Enter expressions using proper mathematical syntax.** Invalid or incorrectly formatted expressions may not be evaluated correctly.

## Tech Stack

- Python

## Run the Application

```bash
python main.py
```

Replace `main.py` with the actual filename of the calculator script if it differs.
